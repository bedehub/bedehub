Laravel Developer & Security Enthusiast
---------------------------------------

Halo! Gue adalah seorang Web Developer yang fokus membangun ekosistem platform digital yang cepat dan aman. Perjalanan tech gue dimulai sejak lulus dari SMK Nurul Huda, dan saat ini gue aktif mengembangkan serta me-maintain platform seperti BedeTopUp (platform top-up game) dan Warung Bede (platform portal berita).

Saat ini, tech stack andalan gue adalah Laravel, Livewire, dan Tailwind CSS. Gue sangat peduli dengan urusan Web Security (Penetration Testing) dan Performance Optimization untuk memastikan aplikasi berjalan tanpa bottleneck. Di luar rutinitas coding, gue biasanya ngoprek dan tuning berbagai distro Linux (Ubuntu, Parrot Security, Pop!\_OS) untuk environment development gue.
